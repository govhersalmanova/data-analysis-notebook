# Portfolio development roadmap

## Strengthen the current notebooks

1. Record the exact original automobile dataset source, version, and reuse rights. Add the input or a reliable retrieval method where permitted.
2. Record the 911 course/template attribution and exact data snapshot. Preserve its guided-project status.
3. Run both notebooks from a clean session against those inputs; retain a tested environment and refreshed outputs.
4. In an independently developed 911 analysis, use groupby.size() for call counts, chronological weekday ordering, year-month grouping, and coverage-aware interpretation of incomplete months. Keep the original guided notebook as a reference.
5. Export selected figures and add a short independent interpretation to each case study.

## Target: four to six substantial pinned repositories

Currently the public portfolio contains two project repositories and three analyses. Do not count a profile README, duplicate notebook copies, or empty scaffolds as additional projects.

| Priority | Proposed project | Evidence required before pinning |
| --- | --- | --- |
| 1 | Existing e-commerce case study | Dataset, notebook, SQLite queries, visuals, KPI definitions, reproducible execution |
| 2 | Existing Python notebook collection | Exact data sources, attribution, clean-run outputs, focused findings |
| 3 | Sales performance dashboard | Actual Power BI file or equivalent dashboard, data model, DAX/metric definitions, screenshots, business questions |
| 4 | SQL customer analytics | Schema and seed data, joins, CTEs, window functions, cohort/retention definitions, validated results |
| 5 | Reproducible data pipeline | Ingestion, validation, transformations, database loading, repeatable runs, failure handling, documentation |
| 6 | Baseline machine learning study | Licensed data, target definition, leakage-safe train/test split, baseline, justified metrics, error analysis, limitations |

Projects 3–6 are proposals, not completed work. Choose the strongest finished work for the profile as these become available. A smaller set of reproducible projects is preferable to unsupported completion claims.
